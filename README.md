
# 🌍 Air and Noise Pollution Mapping System

## 📌 Project Overview

The Air and Noise Pollution Mapping System is a web-based application developed using Python Flask. It helps users monitor and visualize air and noise pollution data through an interactive map.

## 🛠 Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Leaflet Map

## ✨ Features

- Air Pollution Monitoring
- Noise Pollution Monitoring
- Interactive Map Visualization
- Pollution Data Management
- User-Friendly Interface

## 🎯 Project Objective

The main objective of this project is to provide an interactive platform for monitoring and visualizing air and noise pollution levels. It helps users understand pollution information through map-based visualization.

## 💡 Project Benefits

- Easy visualization of pollution data.
- Helps users understand environmental pollution.
- Provides interactive map-based information.
- Supports pollution data management.
