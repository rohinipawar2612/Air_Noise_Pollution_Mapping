# Air and Noise Pollution Mapping System

## Project Overview
The Air and Noise Pollution Mapping System is a web-based application developed using Python Flask. It helps users monitor and visualize air and noise pollution data through an interactive map.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Leaflet Map

## Features
- Air Pollution Monitoring
- Noise Pollution Monitoring
- Interactive Map Visualization
- Pollution Data Management
- User-Friendly Interface

## Installation

1. Clone the repository:
   `git clone YOUR_GITHUB_REPOSITORY_URL`

2. Open the project folder.

3. Install required packages:
   `pip install flask`

4. Run the application:
   `python app.py`

5. Open your browser and visit:
   `http://127.0.0.1:5000/`
